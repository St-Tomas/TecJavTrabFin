Framework: "ScaffoldJ" 

Aplicacion que lo implementa: "Sistema de gestion de Ferreteria"
Una aplicacion de consola para la administracion y consulta de inventario en una ferreteria. Permite a clientes autenticarse. consultar catalogo de herramientas y materiales, y verificar stock. Los administradores posen permisos exclusivos para dar de alta nuevos productos, modificar precios y actualizar inventario.
