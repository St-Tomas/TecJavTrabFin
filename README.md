Framework: "ScaffoldJ" 

Aplicacion que lo implementa: "Sistema de gestión de Ferretería"
Una aplicación de consola para la administración y consulta de inventario en una ferretería. Permite a clientes autenticarse. consultar catálogo de herramientas y materiales, y verificar stock. Los administradores posen permisos exclusivos para dar de alta nuevos productos, modificar precios y actualizar inventario.
